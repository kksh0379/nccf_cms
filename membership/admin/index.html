적용된 조회 조건 없음
1. 회원 분류 추가목록에서 회원을 체크하고 ‘분류 일괄 추가’를 누릅니다.
2. 조회 조건 선택조회할 회원 분류를 선택하고 하나라도/모두 포함을 정합니다.
3. 조회 또는 저장바로 조회하거나 반복 사용할 조회 조건으로 저장합니다.
조회할 회원 분류 선택
분류명은 조회 조건으로 선택합니다. 오른쪽 ×를 누르면 해당 분류가 모든 회원과 저장된 조회 조건에서 삭제됩니다.
